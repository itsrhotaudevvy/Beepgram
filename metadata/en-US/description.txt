Beepgram is a third-party Telegram client for Android. It is based on Nagram, NekoX and the official Telegram for Android sources.

It keeps the native Telegram experience and Nagram's customization features. It also includes the foundation of a network-neutral bridge framework, which is intended to let chats from other networks appear as ordinary Telegram dialogs without a Matrix server.

Beepgram is not affiliated with Telegram or the Nagram project. It uses its own name, icon, signing key and Telegram API credentials.

Source code: https://github.com/itsrhotaudevvy/Beepgram (GPL-3.0)
