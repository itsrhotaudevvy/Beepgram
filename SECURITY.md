# Security policy

Report vulnerabilities in Beepgram's own changes (the bridge framework, build and signing setup,
branding changes) **privately** through
[GitHub private vulnerability reporting](https://github.com/itsrhotaudevvy/Beepgram/security/advisories/new).

Report issues in code inherited from Telegram for Android or Nagram upstream as well, since most
of the client comes from there.
